BOX Drive Backup

A personal file-management integration operated by Yalm (GitHub: travelvector).

This integration uses rclone to access the operator's Google Drive for personal backups and Colab project files. Authorized runtimes can read project source and inputs and save generated outputs back to Drive. It is not a public sign-up service or a Google product.

Google access is granted through OAuth. Each account owner controls whether to grant or revoke access.
