Privacy policy

Effective date: 15 October 2026

BOX Drive Backup is a personal rclone integration operated by Yalm (GitHub: travelvector).

Google Drive data

The integration accesses file names, metadata and file contents as needed for user-directed backups, file management and Colab project work. Write access permits saving and updating the requested files. OAuth permissions may cover more files than an individual task uses.

Storage and processing

Files remain in the account owner's Google Drive or are transferred to the operator's computers, backup destinations or authorized Colab runtimes for the requested task. OAuth credentials are stored in configuration used by those runtimes and must not be published in notebooks or this website. Local caches and backups can persist independently of Drive files.

Use and disclosure

The integration does not use Google user data for advertising, sale or training generalized AI models. Data is processed only for the operator's requested file and project workflows. Google Drive, Google Colab and any explicitly selected storage destination process data under their own applicable terms.

Control and deletion

The account owner may revoke access in Google Account third-party connections, remove saved OAuth credentials, and delete files or backups from each storage destination. Revocation prevents further authorized access but does not itself erase existing copies.

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
