Privacy policy

Effective date: 18 October 2026

Yalm Local Dev is a personal integration operated by Yalm (GitHub: travelvector).

Google data accessed

The integration accesses account identity, Google Drive file names, metadata and contents, and requested Gmail messages and settings, Calendar data, Google Docs and Google Sheets contents. Drive permissions allow user-directed file creation, updates and deletion. The configured Gmail, Calendar, Docs and Sheets permissions are read-only. OAuth permissions can cover more data than an individual task uses.

Purpose and processing

Google data is used for the operator's requested search, reading, file management, project and assistant workflows. When the operator runs an AI-assisted task, the requested data may be included in tool results and conversation context sent to the selected assistant service. Google and those selected services process data under their applicable terms and account settings.

Storage and retention

OAuth credentials are stored in local tool configuration. Requested data and generated outputs may remain in Google Workspace, local working files, backups, tool logs or assistant conversation history. Copies can persist independently of their source files. This static website does not request OAuth credentials or collect Google Workspace contents; its hosting provider may process ordinary web-request logs.

Use and disclosure

The integration does not sell Google user data, use it for advertising or use it to train generalized AI models. Transfers are limited to the services and destinations used for the operator's requested workflow. Credentials and private Workspace data must not be published on this website or in public source repositories.

Control and deletion

The account owner can revoke authorization in Google Account connections, remove local OAuth credentials, and delete files, backups or conversation records from their respective storage destinations. Revoking authorization stops further authorized access; it does not erase previously stored copies.

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
